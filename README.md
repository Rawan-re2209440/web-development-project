# Bookworms

A social media platform concept for book readers, built as a university web development team project.

## Overview

Bookworms is a front-end web application where readers can share and interact around books. The project uses browser `localStorage` to keep data on the client side, so no server or database is required.

## Technologies

- HTML
- CSS
- JavaScript (vanilla)
- Browser localStorage
- Git and GitHub for team collaboration

## Project Structure

- `BookWorm/` - the Bookworms web application
- `stats-app/` - a separate statistics-related part of the team project
- `Project_Report.docx` - the project report

## How to Run

1. Clone or download this repository.
2. Open the `BookWorm` folder.
3. Open `index.html` in any modern web browser.

> If the main page has a different file name, open that HTML file instead.
